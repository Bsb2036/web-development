# Web Development Portfolio

## Gestalt principles

- **Proximity:** Project cards keep each eyebrow, heading, description, and link together, while consistent gaps separate one project from the next.
- **Similarity:** Repeated cardboard borders, bubble-wrap surfaces, rounded shapes, and teal accents make navigation, cards, and buttons feel like parts of the same portfolio across pages.

## Shared color palette

The page backgrounds, cards, text, navigation, and controls use the same palette tokens in each page stylesheet.

| Role | Color |
| --- | --- |
| Cardboard background | `#d8b687`, `#c99b68`, `#e6c99e`, `#b98754` |
| Bubble-wrap surfaces | `#e7f8fc`, `#a9deeb` |
| Text | `#493421`, `#382716`, `#21170d` |
| Teal accents | `#176a80`, `#12566a` |
| Gold illustration accents | `#fff7db`, `#ffdb67`, `#d99523` |

The monkey artwork uses a few character-specific illustration colors; shared page chrome and readable content stay within the palette above.
